# Результат работы

**Описание**

В программе проверяется класс Student для варианта 4

Реализованы:

- создание студентов разными конструкторами
- вывод данных через const-методы
- сессия, перевод, день рождения, отчисление и восстановление
- проверка неправильных данных и сохранения состояния
- проверка независимости студентов и их групп
- проверка копирования, присваивания и счетчика объектов
