# Требования работы

Задание: https://aleksandr-003.github.io/labs/OOP_z/Labs1_2.html

Общие требования: https://aleksandr-003.github.io/labs/OOP_z/OOP.html

**Проверка требований**

| № | Требование | Реализация в готовой работе |
| --- | --- | --- |
| 1 | Не менее 4 полей различных типов, одно поле класса | `std::string`, `int`, `double`, `bool`, `Group` в `Student` |
| 2 | Минимум 3 типа данных | У полей 5 различных типов |
| 3 | Все поля private | Оба класса, включая статический счётчик |
| 4 | Публичный интерфейс доступа | Методы чтения и осмысленные действия |
| 5 | Конструктор без аргументов | Корректные начальные значения |
| 6 | Параметризованный конструктор | Два перегруженных конструктора `Student` |
| 7 | Не менее 3 способов создания | Без аргументов, с 3 аргументами, с 4 аргументами, копирование |
| 8 | Список инициализации | Конструкторы обоих классов |
| 9 | Методы получения данных | Геттеры для всех читаемых полей |
| 10 | const у методов чтения | Все нестатические методы чтения |
| 11 | Не менее 3 методов изменения | Пять действий студента |
| 12 | Нет бессмысленных setter-методов | Сессия, перевод, день рождения, отчисление, восстановление |
| 13 | Сохранение корректного состояния | Проверки конструкторов и действий до изменения полей |
| 14 | Минимум 3 условия до реализации | `pages/design.md` в первом коммите |
| 15 | Вывод информации | `printInfo() const` |
| 16 | Явный деструктор | `~Student()` и `~Group()` |
| 17 | Не менее 3 объектов в main | Три студента и отдельные копии для проверки |
| 18 | Разные конструкторы в main | Три разных конструктора и конструктор копирования |
| 19 | Независимость объектов | Проверка всех полей остальных студентов после изменения первого |
| 20 | Разделение файлов | `include/*.h`, `src/*.cpp`, `src/main.cpp` |
| 21 | Счётчик существующих объектов | `objectCount`, `getObjectCount()`, проверки времени жизни |

**Обязательные этапы проверки в main**

1. Создание объектов разными конструкторами
2. Вывод начального состояния
3. Правильные действия
4. Неправильные действия и аргументы конструкторов
5. Повторный вывод и проверка сохранения состояния
6. Проверка независимости объектов

**Общие требования**

- Git: отдельные осмысленные коммиты по этапам и метки версий
- Doxygen: русские комментарии к классам и функциям, файл `Doxyfile`
- PlantUML: классы и связь между ними в `uml/student.puml`
- Понимание кода: описание полей, действий, условий корректности и работы счётчика в документации
