# Проектирование классов

**Предметная область**

Объект представляет студента. Студент имеет имя, возраст, средний балл, количество сданных сессий, состояние обучения и учебную группу

Студент может сдать сессию, перейти в другую группу, отметить день рождения, быть отчислен или восстановлен

Недопустимы пустое имя, возраст вне допустимых границ, неправильный средний балл и группа с неправильным номером курса. Отчисленный студент не может сдавать сессию или переводиться в другую группу

**Условия корректности**

Условия определены до реализации классов:

1. Имя студента и название группы не должны быть пустыми или состоять только из пробелов
2. Возраст студента должен быть от 16 до 100 лет. Это границы, выбранные для данной модели
3. Средний балл равен 0, если сессий ещё не было, или находится в пределах от 2 до 5. Значения NaN и бесконечность недопустимы
4. Курс группы находится в пределах от 1 до 6
5. Количество сессий неотрицательно. Нулевое количество соответствует нулевому среднему баллу
6. Сессии и перевод доступны только студенту, который учится

**Класс Group**

| Элемент | Описание |
| --- | --- |
| Имя класса | `Group` — учебная группа |
| Поля | `name` (`std::string`), `course` (`int`), все private |
| Конструкторы | Без аргументов и с названием и курсом |
| Методы чтения | `getName()`, `getCourse()`, `printInfo()`, все const |
| Методы изменения | `advanceCourse()` — переход на следующий курс |
| Инварианты | Непустое название, курс от 1 до 6 |

**Класс Student**

| Элемент | Описание |
| --- | --- |
| Имя класса | `Student` — студент |
| Поля | `fullName` (`std::string`), `age` (`int`), `averageGrade` (`double`), `sessionCount` (`int`), `studying` (`bool`), `group` (`Group`), все private |
| Счётчик | Статическое private поле `objectCount` — количество существующих студентов |
| Конструкторы | Без аргументов; имя, возраст и группа; имя, возраст, средний балл и группа; копирование |
| Методы чтения | Получение всех полей, вывод информации и получение счётчика |
| Методы изменения | `passSession()`, `transferToGroup()`, `celebrateBirthday()`, `expel()`, `restore()` |
| Инварианты | Условия корректности приведены выше |

При создании без аргументов студент получает имя «Новый студент», возраст 18 лет, группу «Без группы» первого курса и нулевой средний балл. Он находится в состоянии обучения

Параметризованный конструктор с ненулевым средним баллом считает этот балл результатом одной уже сданной сессии. Дальше `passSession()` вычисляет среднее с учётом количества сессий

Неправильные аргументы конструкторов вызывают `std::invalid_argument`. Неправильные действия возвращают `false`, состояние объекта сохраняется

Группа хранится внутри студента по значению. Изменение одного студента не меняет другого студента или исходную группу

Каждый успешно созданный студент увеличивает счётчик на один. Деструктор уменьшает его на один. Копирование создаёт ещё один объект, а присваивание изменяет существующий и не меняет счётчик
