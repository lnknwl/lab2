# Объяснение кода

**Поля и методы**

`Student` хранит данные одного студента. Все поля private, поэтому изменить возраст или средний балл напрямую из `main()` нельзя

Для чтения используются методы `getFullName()`, `getAge()` и другие геттеры. Они объявлены const, потому что не меняют объект. `getGroup()` возвращает константную ссылку: группу можно прочитать, но нельзя изменить через эту ссылку

`Group` хранит название и курс. Внутри студента хранится копия группы, поэтому изменения исходной группы не затрагивают студентов

**Конструкторы**

В программе показаны три обычных способа создания:

```cpp
Student first;
Student second("Иван Петров", 20, group);
Student third("Анна Иванова", 21, 4.5, group);
```

Первый конструктор задаёт начальные значения, второй создаёт студента без сессий, третий принимает средний балл

Первые два конструктора вызывают третий. Это позволяет не повторять проверки. Поля третьего конструктора заполняются в списке инициализации, который находится после двоеточия

Если имя, возраст или балл неправильные, конструктор выбрасывает `std::invalid_argument`. В `main()` эта ошибка перехватывается через `try` и `catch`

Отдельно есть конструктор копирования:

```cpp
Student copy(second);
```

Он создаёт нового студента с такими же данными. После этого объекты можно изменять независимо

**Изменение состояния**

- `passSession(grade)` добавляет результат сессии и пересчитывает средний балл
- `transferToGroup(newGroup)` меняет учебную группу
- `celebrateBirthday()` увеличивает возраст на один год
- `expel()` меняет состояние на «отчислен»
- `restore(newGroup)` восстанавливает студента в указанной группе

Перед изменением полей проверяется допустимость действия. При отказе метод возвращает false и не меняет объект

Средний балл считается по формуле:

```text
новый средний = (старый средний * количество сессий + новый балл)
                / (количество сессий + 1)
```

Если сессий не было, средний балл равен нулю. После сессий с баллами 4 и 5 он равен 4.5. Для балла проверяется `std::isfinite()`, чтобы не допустить NaN и бесконечность

**Счетчик и деструктор**

`objectCount` — статическое поле. Оно одно для всего класса, а не отдельное для каждого студента. Его определение находится в `Student.cpp`

После успешных проверок в конструкторе счетчик увеличивается. Если конструктор выбросил исключение, увеличение не выполняется

`~Student()` вызывается при завершении времени жизни объекта и уменьшает счетчик. В `main()` студенты созданы внутри блока. До блока счетчик равен 0, после создания трёх студентов — 3, после выхода из блока — снова 0

Копирование создаёт объект и увеличивает счетчик. Присваивание `third = copy` переносит данные в уже существующий объект и не увеличивает счетчик. Для присваивания используется стандартная реализация `= default`

Динамическая память вручную в этой работе не выделяется. Строки и группа освобождаются автоматически после выполнения тела деструктора

**Проверка программы**

`check()` сообщает только об ошибках. Успешные проверки не печатаются отдельным списком. `sameState()` сравнивает все данные студентов через методы чтения

Для проверки отказа сначала сохраняется копия студента, потом выполняется неправильное действие и сравнивается состояние. Для проверки независимости сохраняются данные второго и третьего студентов, изменяется первый и проверяется, что остальные не изменились

Есть проверки пустых имён, возраста 15 и 101, неправильных баллов, повторного отчисления, сессии и перевода отчисленного студента. Также проверены допустимые границы возраста и баллов, копирование и присваивание
